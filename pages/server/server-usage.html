目次の使い方

  • 左の一覧から読みたい項目を選びます
  • 部（「サーバーとルール」など）は仕切りの見出しです。押せません
  • 大大見出し（「ミッション」など）と大見出し（「ミッションの基本」など）は、押すと開いたり閉じたりするだけで、ページは変わりません
  • その下の小見出しを押すと、そのページが開きます
  • ページの一番下に「前のページ／次のページ」があるので、順番に読み進めることもできます

大大見出しと大見出しに付いている * は、参加の前に読む項目です。

開き方と閉じ方

開き方は 2 通りです。

  • インベントリ（TAB）を開き、上に出ているオレンジの 📖 GUIDE を押します
  • /ash_guide コマンドを使います。どこにいても開けます

インベントリから開くと、インベントリは閉じます。読み終わったら開き直してください。

/ash_guide は好きなキーに割り当てられます。GTAの設定 > キーバインド > FiveM を開き、「プレイヤーガイドを開く」に空いているキーを設定してください。

閉じるときは右上の ✕ か ESC です。
