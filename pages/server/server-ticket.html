チケットの出し方・閉じ方

アドミンへの報告・確認・申請の窓口

ルール違反の報告、判断に迷ったときの確認、各種の申請は、すべて Discord のチケットから行います。ゲーム内やチャットで直接アドミンに声をかける必要はありません。

出し方と閉じ方

  1. Discord のチャンネル一覧から ADMIN宛 のカテゴリを開き、#チケット問い合わせ を開きます
  2. Create ticket のボタンを押します
  3. チケットが正常に作られると、#チケット問い合わせ に次のような投稿がされます
  4. 専用のチャンネル（ticket-0000 のような名前）が作られます

    ここのチャット欄に用件を書いて送ってください。

このチャンネルは自分と運営にしか見えません。他のプレイヤーからは見えないので、そのまま書いてかまいません。

間違えて作ってしまったときは、Close のボタンを押せば自分で閉じられます。

用件が済んだチケットは、アドミンが閉じます。自分で閉じる必要はありません。

チャンネル使うとき
#チケット問い合わせ報告・確認・各種の申請
#ロール申請ロールの申請
アドミンは同時にいくつもの対応をしているため、返答までに時間がかかることがあります。あらかじめご了承ください。

書くときに気をつけること

  • どのような問題があり、ADMIN にどうしてほしいのかを明確に書いてください。これが一番大事です
  • 用件を最初に書いてください。「citizen申請です」のように、何のチケットかが分かるようにします
  • いつ・どこで起きたかを書いてください。時刻が分かると確認が早くなります
  • クリップや動画は添付してください。文章だけでは確認できないことがあります

チケットで送るもの

用件一緒に送るもの
ルール違反の報告証拠のクリップ（トラブルを起こさないために）
判断に迷ったときの確認何をしたいか、どういう状況か
補填の依頼下の「補填を頼むとき」を参照
citizen の申請動画（citizen）
配信の申請配信 URL と FiveM のユーザーネーム（配信について）
開業の申請店の内容（企業・店舗）
団体設立の相談代表者がアドミンとの面談を申し込む（レジスタンス）
