Discord ID の調べ方

アドミンに求められたときのために

アドミンから Discord のユーザーID を聞かれることがあります。問い合わせの対応や、ロールの設定に使うものです。17〜19桁の数字で、次のような見た目をしています。

ユーザーID123456789012345678
⚠️ ユーザー名とは別物です @ から始まる名前（ユーザー名）ではありません。数字だけのものです。
ユーザー名は後から変更できますが、ユーザーIDは一生変わりません。だからこちらを使います。

先に開発者モードを入れる

ユーザーIDは、初期状態では表示されません。まず開発者モードを有効にします。一度入れれば、次からは不要です。

  1. Discord のユーザー設定（歯車のマーク）を開きます
  2. 左のメニューから詳細設定を選びます
  3. 開発者モードをオンにします

IDをコピーする

パソコンの場合

  1. 画面左下にある自分のアイコンを右クリックします
  2. メニューからユーザーIDをコピーを選びます

スマートフォンの場合

  1. 自分のプロフィールを開きます
  2. 右上の三点マークを押します
  3. ユーザーIDをコピーを選びます

コピーできたら、そのまま貼り付けて伝えてください。

Discord の更新で、項目の名前や場所が少し変わることがあります。詳細設定の中に開発者モードが見つからないときは、アドミンに聞いてください。

うまくいかないとき

  • 右クリックしてもメニューに出てこない — 開発者モードがオンになっていません。もう一度設定を確認してください
  • 数字ではなく名前がコピーされた — 「ユーザー名をコピー」を押しています。ユーザーIDをコピーのほうを選んでください
  • 他の人のIDをコピーしてしまった — 自分のアイコンから操作してください。サーバーの参加者一覧から選ぶと、その人のIDになります

チケットでの問い合わせや、ロールに関する相談のときに聞かれます（トラブルを起こさないために）。
