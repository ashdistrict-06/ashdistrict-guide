読むもの・条件・参加のしかた

このガイドには、参加するうえで必要な情報がまとまっています。参加の前に、左の【*】の付いている項目はすべて目を通してください。

参加条件

参加できる人

  • 日本語で会話・意思疎通ができること
  • 18歳未満でないこと（高校生不可）
  • 現実世界の一般的な常識を持ち合わせていること

参加の前に読むもの

  1. 概要 — 概要
  2. 世界観 — 崩壊後の世界 / 勢力と職業 / エリア区分
  3. 一般ルール — 禁止行為 / トラブルを起こさないために / 処分について / 配信について / citizen
  4. 組織ルール — 軍（ARC） / レジスタンス / 救護団体（FMU） / メカニック / 企業・店舗 / 服装
  5. 戦闘系ルール — PvP・非PvPゾーン / 特殊物資争奪戦
ルールに明記されていない行為でも、運営の判断で禁止になる場合があります。迷う内容は独断で行動せず、チケットで先に確認してください（チケットの出し方・閉じ方）。

参加のしかた

Discord でリアクションを1つ押すだけです。

  1. このガイドの【*】が付いている項目をすべて読みます
  2. Discord の #ロール申請 を開きます
  3. チャンネルにあるメッセージに ✅ のリアクションを押します

押すとすぐにロールが付き、参加できます。

⚠️ リアクションは「読んで理解した」という同意です 読んでいなかった・知らなかったは通用しません。 押す前に、【*】の付いた項目をすべて読んでください。
組織に所属すると、サーバー全体のルールに加えてその組織のルールも適用されます。軍とレジスタンスには別の処分もあります（処分について）。
