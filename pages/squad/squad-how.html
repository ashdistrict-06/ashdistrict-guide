使い方

組んで、仲間を呼ぶ

スクワッドは一緒に行動する仲間の集まりです。組んでおくと、スクワッド用のミッションを一緒に受けられます。

スクワッドを作る

F6 でスクワッド管理の画面が開きます（キー割り当て）。

  1. スクワッド名を入力します
  2. スクワッドを作成を押します
  • 作った人がスクワッドリーダーになります
  • 作ると画面の右上にメンバーが出ます。表示は F11 で消したり出したりできます
  • そのあとスクワッドで何かするときは、いつでも F6 で管理画面を開きます

仲間を招待する

管理画面の招待から送ります。方法は 2 つです。

方法やり方
近くのプレイヤーを検索そばにいる人の一覧から選びます
ID 招待相手のサーバー ID を入れて送ります

サーバー ID は、街にいるときに画面の右上に出ています（チケットの出し方）。

招待されたら

招待が届くと画面に案内が出ます。

キーできること
E承諾して加わる
G断る
ミッションを一緒に受けたいときは、先にスクワッドを組んでおいてください。リーダーが受注したあとに加わった人は、そのミッションには参加できません（スクワッドで進める）。
