チュートリアル

最初に受けるクエスト

キャラクターを作った場所の近くに、オージー教導官というNPCが立っています。ここからチュートリアルを受けられます。

クリアをおすすめします。基本の操作を覚えられるうえ、メインストーリーの入口にもなっています。ワイプのあとも、メインストーリーはチュートリアルを済ませていることが前提です。

受ける

  1. 心の目で話しかけます（よく使う言い方）
  2. クエストを受けるを選ぶと、受けられるクエストの一覧が出ます
  3. チュートリアル：レギオンへを選びます
  4. 話を聞いたあと、引き受けるを選ぶと始まります

進める

画面の左に、いまやることが表示されます（トラッカー）。これに従って進めてください。

表示が出ていないときは F5 を押してください。トラッカーは F5 で出したり消したりできます。まれに最初から出ていないことがあります。
  • 最後の目的地である記録者の場所は、地図の黄色い吹き出しが目印です
  • 記録者はレギオンの中に立っています
  • 話しかけるとクリアになり、報酬を受け取れます（報告して受け取る）

そのあとは

チュートリアルが終わったら、そのままメインストーリーに進めます。

記録者に話しかけて章を選ぶと、選んだ章から始められます。詳しくは記録者と章選択を読んでください。
