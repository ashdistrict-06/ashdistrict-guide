片付け方と報酬

工具を持って、道路の物を長押しで片付ける

必要なもの

アイテム使い道
撤去工具セットこれが無いと片付けられません。片付けるたびに傷み、大きい物ほど傷みが早いです
撤去工具の手入れキット使うと、持っている撤去工具セット1つの耐久が満タンに戻ります

どちらもサバイバル品作成の作業台で、誰でも作れます（クラフト）。工具が壊れたら手入れキットで直せば、作り直す必要はありません。

撤去工具セットはバックパックの中に入れないでください。バックパックの中にあると、持っていても「撤去工具セットが必要」と出ます。

片付ける物を探す

/roadevents で WORLD EVENTS の画面が開きます（キーの初期設定は F10）。開催中の区間が近い順に並び、片付け期限と元に戻る日も見られます。

区間の「ここへ案内」を押すと、その区間で一番近い残りの物に地図の印が立ちます。

片付ける

  1. 車から降りて、片付ける物に近づきます
  2. 「[E] 長押しで片付ける」と出たら、E を長押しします
  3. バーが最後まで進むと片付け完了です。途中でやめるときは X を押します

大きい物は少し離れていても届きます。表示が出ないときは、物の周りを歩いてみてください。

報酬

  • 片付けるたびに廃材が手に入ります。大きい物ほど多く出ます
  • 決まった回数ごとに、廃材と一緒にレア報酬が出ます。あと何回かは WORLD EVENTS で見られます
  • この回数は全区間で共通に数えます。イベントの片付け期間が全部終わると 0 に戻ります
  • 1日に片付けられる数に上限がある回もあります。上限は WORLD EVENTS に出ます

廃材はリサイクラーに入れると、クラフトに使う素材がいくつか出ます（ジョブ用のリサイクラーでは分解できません）。

片付ける物はセーフゾーンの外にもあります。感染者に気をつけてください（セーフゾーンと外）。インベントリに空きが無いと報酬を受け取れないので、空けてから行きましょう。
